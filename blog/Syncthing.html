How to Sync Files Between Windows 10 and Android for Free with Syncthing

A complete, zero-cloud setup guide for syncing mismatched folders across your PC and phone—without touching your Windows C:\ drive or paying a dime.

Keeping files synchronized between a Windows PC and an Android smartphone usually forces an annoying compromise: either pay for cloud storage and upload private files to third-party servers, or manually plug in a USB cable and drag-and-drop folders every few days—hoping you don't accidentally overwrite your latest edits.

Syncthing eliminates both problems. It is a free, open-source, peer-to-peer synchronization tool that transfers files directly between your devices over your local Wi-Fi, mobile hotspot, or USB tethering—with zero cloud middlemen, no file size caps, and full end-to-end encryption.

Why It Works So Well for Messy Folder Structures

Most sync tools force your phone and PC to mirror an identical directory tree. Syncthing instead pairs directories using a shared Folder ID, letting each device map that ID to wherever the files naturally live:

  • Pair 1 (work-docs): Maps to D:\Projects\Active\Docs on Windows and /storage/emulated/0/Download/Work on Android.
  • Pair 2 (notes-vault): Maps to D:\Notes\Markdown on Windows and /storage/emulated/0/Documents/Obsidian on Android.

Edit a document on your phone during a commute, and the moment your phone and PC connect, Syncthing updates your PC copy automatically—and vice versa.

Step 1: Set Up Syncthing on Windows 10 (Zero C:\ Drive Usage)

By default, Windows installers drop programs into C:\Program Files and store Syncthing's database and file indexes inside %LOCALAPPDATA%\Syncthing on your main OS drive. If your C:\ drive is a small SSD you want to keep spotless, use the portable ZIP build with the --home startup flag on a secondary drive (such as D:\).

Step 1.1 Download the Portable Windows ZIP

Visit syncthing.net/downloads and download the Base Syncthing ZIP archive for Windows Intel/AMD (64-bit) (for example, syncthing-windows-amd64-v2.x.x.zip). Avoid third-party .exe installers so nothing writes to C:\.

Verify: Confirm you downloaded a .zip archive rather than an installer executable.
Step 1.2 Extract to Your Secondary Drive

Create a folder on your secondary drive—such as D:\Syncthing—and extract syncthing.exe directly into it. Inside D:\Syncthing, create an empty subfolder named Home (D:\Syncthing\Home) to store your database, certificates, and configuration.

Verify: Both D:\Syncthing\syncthing.exe and the empty folder D:\Syncthing\Home exist.
Step 1.3 Create a Portable Launcher Script

Open Notepad, paste the two lines below, and save the file as StartSyncthing.bat inside D:\Syncthing (be sure to set Save as type to All Files so Windows doesn't name it StartSyncthing.bat.txt): 

cd /d "D:\Syncthing"
start "" "D:\Syncthing\syncthing.exe" --home="D:\Syncthing\Home" --no-console

Passing --home="D:\Syncthing\Home" before the very first launch guarantees Syncthing never creates a default folder on your C:\ drive, while --no-console keeps a black command prompt window from cluttering your taskbar.

Verify: StartSyncthing.bat sits right next to syncthing.exe.
Step 1.4 Launch and Confirm Storage Paths

Double-click StartSyncthing.bat. Your browser will automatically open the Syncthing Web GUI at http://127.0.0.1:8384. Click Actions → About in the top-right corner to inspect where Syncthing is storing its files.

Verify: Both Configuration and Database paths start with D:\Syncthing\Home, and %LOCALAPPDATA%\Syncthing does not exist on C:\.
Optional: Auto-Start on Windows Boot Want Syncthing ready whenever you log in? Right-click StartSyncthing.bat → Create shortcut. Press Win + R, type shell:startup, press Enter, and move the shortcut into that Startup folder. The shortcut uses virtually zero space while keeping all program data on D:\.

Step 2: Set Up Syncthing-Fork on Android

The legacy official Syncthing Android app was retired, so you should install Syncthing-Fork—the actively maintained community edition with better battery controls and modern Android storage support.

Step 2.1 Install Syncthing-Fork

Download and install Syncthing-Fork from F-Droid or directly from its GitHub Releases page.

Verify: Syncthing-Fork appears in your Android app drawer.
Step 2.2 Grant Storage & Battery Permissions

Launch Syncthing-Fork and complete the two setup prompts:

  1. Grant All files access so Syncthing can read and write across arbitrary directories on internal storage or an SD card.
  2. Disable Battery Optimization for Syncthing-Fork so Android doesn't terminate an active sync mid-transfer.
Verify: The app opens to its main tabs (Folders, Devices, Status) with no warning banners.
Step 2.3 Configure 1-Tap Manual Sync (Zero Idle Battery Drain)

If you prefer syncing strictly on demand rather than keeping a background service running:

  1. Open the left menu (☰) → Settings → Run Conditions.
  2. Uncheck Start on boot and disable automatic run triggers (or restrict syncing to Wi-Fi / charging only).
  3. Swipe down your Android Quick Settings shade, tap the pencil/edit icon, and drag the Syncthing tile into your active quick toggles.
Verify: Tapping the Quick Settings tile starts Syncthing on demand, syncs your folders, and tapping it again shuts the service down cleanly.

Step 3: Pair Devices & Map Mismatched Folders

With both apps running on the same network, linking them takes less than two minutes.

Step 3.1 Exchange Device IDs via QR Code
  1. On your Windows Web GUI (127.0.0.1:8384), click Actions → Show ID to display your PC's QR code.
  2. On Android, open Syncthing-Fork → Devices tab → tap + → tap the QR scanner icon next to Device ID and scan your PC monitor. Name the device (e.g., Windows-PC) and tap the checkmark (✓).
  3. Within 10 seconds, a yellow banner will appear on your PC Web GUI: "New device wants to connect." Click Add Device → Save.
Verify: Both devices show a green Connected status under each other's Devices tab.
Step 3.2 Map Your First Folder Pair
  1. On your PC Web GUI, click + Add Folder.
  2. In the General tab, give the folder a friendly Folder Label (e.g., Work Docs), a clean Folder ID (e.g., work-docs), and point Folder Path to your directory on D:\ (e.g., D:\MyFiles\Work).
  3. Switch to the Sharing tab and check the box next to your Android phone.
  4. Switch to the File Versioning tab, select Staggered File Versioning (explained below), and click Save.
  5. On Android, tap the incoming notification "Windows-PC wants to share folder work-docs", select your matching Android folder path (e.g., /storage/emulated/0/Documents/Work), set File Versioning to Trash Can, and tap ✓.
Verify: Both devices display Up to Date in green, and test files dropped into either folder appear on the other device within seconds.

Repeat Step 3.2 for every additional directory pair you want to synchronize, assigning each pair its own unique Folder ID.

Step 4: Protect Your Files with File Versioning

Because Syncthing mirrors deletions and overwrites across devices, turning on File Versioning is essential. Instead of permanently destroying an overwritten or deleted file, Syncthing moves the older copy into a hidden .stversions folder inside your synced directory.

Versioning Mode How It Works Best Used On
Staggered Keeps dense snapshots of recent edits (1 per 30s for the first hour, hourly for 24h, daily for 30 days, weekly thereafter) up to a max age (default: 365 days). Windows PC — ideal primary safety net where storage is abundant.
Trash Can Keeps only the single most recent overwritten or deleted version for a set number of days (default: 30 days). Android Phone — acts as a lightweight "undo" button without eating phone storage.
Simple Retains the last N versions of every changed file (e.g., Keep Versions = 3). Folders with large media or archives where you want a strict version count cap.
External Passes deleted/replaced files to a custom shell script or backup utility. Advanced NAS or custom snapshot workflows.
What Happens If You Edit the Same File on Both Devices? If you modify the exact same file on both Windows and Android before they sync, Syncthing never silently discards your work. It keeps both copies and renames the older edit to filename.sync-conflict-YYYYMMDD-HHMMSS.ext so you can compare and merge them safely.

Step 5: Syncing Over Any Media & Practical Tips

  • Works Without Home Wi-Fi: Turn on your Android phone's portable Wi-Fi hotspot and connect your Windows laptop to it. Syncthing automatically discovers peers over the local hotspot subnet—transferring files at full Wi-Fi speed while using zero cellular data.
  • Works Over a USB Cable: Plug your phone into your PC via USB and enable USB Tethering in Android's network settings. Windows sees a direct local network link to your phone, and Syncthing syncs immediately over the wire.
  • Ignore OS Junk Files: Create a plain text file named .stignore inside the root of a synced folder and add patterns like desktop.ini, Thumbs.db, and .trashed-* so Windows thumbnails and Android trash temp files never clutter your sync queue.
  • Moving Your Home Directory Later: If you ever relocate D:\Syncthing\Home to another drive, shut down Syncthing completely first (Actions → Shutdown), move the folder contents, and update the --home path in StartSyncthing.bat (or set the STHOMEDIR environment variable).
